## About Me

I'm a final-year Industrial and Production Engineering student based in India. I'm fascinated by how factories, supply chains and processes run, and even more by how data can make them run better.

I enjoy cleaning messy datasets, finding the story inside the numbers, and presenting it in a way that helps people make decisions. I'm building my skills toward a career as a data analyst.

- Currently learning: data analysis, SQL and Power BI dashboards
- Currently working on: data analysis projects using Python, SQL and Power BI
- Interested in: production management, process optimization, data-driven decision making
